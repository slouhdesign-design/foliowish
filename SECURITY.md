# Security

FolioWish pre-launch is a static browser application.

- Do not commit API keys, tokens, passwords or user project files.
- The editor must not upload personal photos without an explicit future product/security review.
- `robots.txt` and `noindex` stay active until public launch approval.
- Advertising and analytics scripts are not permitted in the pre-launch branch.
- Any future server endpoint must receive a separate threat-model and privacy review.
