Why we built this

Creative tools should help you tell the story, not learn the software.

FolioWish is a focused design studio for printable keepsakes. The first product is a birthday magazine maker built around real editorial structure.

Focused beats infinite

General-purpose design tools are powerful, but power can become friction when all you want is a thoughtful gift. Choosing a page size, grid, type hierarchy, cover structure, photo rhythm and export settings is design work. FolioWish starts after those decisions.

The editor gives you a useful issue structure, then lets you spend your attention on the part nobody can automate: the memories, photos, jokes, messages and details that make the magazine belong to one person.

Privacy is part of the product

The pre-launch birthday maker compresses photos in the browser and stores the project locally. There is no public account system and no server upload in this version. That is intentional. A birthday keepsake can contain personal photos and private messages, so the default should be conservative.

What “smart” means here

Smart does not have to mean sending everything to a generative AI service. The first Smart Fill feature uses structured prompts and deterministic writing patterns locally, producing a complete editorial starting point from a small amount of context. If AI-assisted writing is added later, it will be optional, clearly disclosed and separated from the core editor.

How FolioWish will grow

The birthday magazine is the first tool because it combines a strong visual outcome with a clear reason to share. The same product philosophy can expand into zines, journals, photo keepsakes, pen-pal pages and other printable formats — but only after the first maker is tested and genuinely useful.
