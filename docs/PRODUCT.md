# FolioWish Product System

## Positioning
A focused browser studio for personal printable keepsakes. First wedge: birthday magazines.

## Product advantage
- Guided issue structure instead of a blank canvas.
- Smart Fill creates a complete editorial starting point locally.
- Eight switchable visual themes.
- Direct photo replacement with local compression.
- Local autosave + downloadable/importable project backups.
- Studio Check before export.
- A4 print-safe overlay and browser PDF workflow.
- No forced signup and no server photo upload in the pre-launch build.

## Current page library
Cover, Profile, Reasons, Photo Story, Letter, Timeline, Playlist, Back Cover.

## Monetization order
1. Earn useful organic traffic and meet quality/policy requirements.
2. Apply for AdSense after public content footprint and user experience are sufficient.
3. Add ads only where they do not obstruct creation or export.
4. Consider optional premium print packs/affiliate printing later; not required for the core product.

## Expansion after validation
Zine maker, birthday newspaper, book-log maker, pen-pal pages, photo album planner, tracking journals, printable mini projects.
