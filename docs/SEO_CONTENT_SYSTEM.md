# SEO + Content System

## Primary product intent
The first search wedge is **birthday magazine maker / birthday magazine template**. The product page is the conversion destination; editorial pages support narrower intents with original guidance.

## Launch cluster
- Birthday magazine maker — product / editor
- Birthday magazine templates — template gallery
- How to make a birthday magazine — process guide
- Best friend birthday magazine ideas — recipient/use-case guide
- 18th birthday magazine ideas — milestone guide
- 21st birthday magazine ideas — milestone guide
- Birthday magazine interview questions — prompt library
- Birthday magazine cover ideas — design guide

## Expansion sequence after evidence
1. Birthday newspaper maker.
2. Birthday magazine for boyfriend / girlfriend / sister / mom.
3. Zine maker.
4. Pen-pal / snail-mail printable tools.
5. Book-log and tracking journal makers.

Expansion is triggered by Search Console, Pinterest and real user behavior. Do not create thin programmatic pages simply to multiply indexable URLs.

## Page quality rule
Every indexable editorial page must provide a distinct search job, original examples, useful internal links and a reason to use the maker. Every tool landing page must include meaningful publisher content around the interactive experience.

## Measurement later
Track impressions, clicks, CTR, top queries, maker starts, Smart Fill usage and PDF exports. Never invent volume/KD data when third-party numbers are unavailable.
