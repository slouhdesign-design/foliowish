# FolioWish workflow

GitHub is the canonical source of truth for this project.

## Operating rule
- Work is not considered complete until it is committed to this repository.
- Local/container copies may be used only as temporary test workspaces.
- Any meaningful code, content, design, SEO, QA or documentation change must be uploaded to GitHub in the same work cycle.
- Do not leave the newest version only in a local sandbox.
- Do not deploy publicly without the explicit launch approval gate.
