Privacy

Pre-launch privacy summary for the browser-based birthday magazine maker.

Current pre-launch behavior

The current editor does not require an account. Magazine text, settings and compressed image data are stored in your browser using local storage. The application does not intentionally transmit your uploaded photos to a FolioWish server in this build.

Project backups

If you download a project backup, the file can contain text and images you added. Store that file as carefully as you would store the original photos. Anyone with the file may be able to view its contents.

Analytics and advertising

Analytics and advertising are not enabled in this pre-launch build. Before public launch, any analytics or advertising configuration will be reviewed for consent, disclosure and regional requirements.

Third parties

The editor has no embedded social widgets, chat trackers or third-party font scripts in the current build. Browser printing and file download features are provided by your browser and operating system.

Before public launch

This page must be updated with the legal operator identity, contact address, applicable analytics/advertising details, retention rules and user rights before the service is opened publicly.
